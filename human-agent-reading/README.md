# 人与智能体共读

> 一本书不是一份待完成的摘要，而是一次和你此刻生活发生摩擦的对话。

`human-agent-reading` 是一套长期共读 Skill。它的起点是：根据使用者的记忆，整理一份 **100 本跨文化、跨学科、跨时代的书单**，分成 **十个章程**；每天针对书单里的一本书，做一次一问一答的拆解对话，让阅读回到真实生活。

它不承诺速读、知识打卡或一百天"完成成长"。它提供的是一段可以持续很久的共同学习关系：人带来新的生活，智能体据此调整选书；书再反过来改变人理解生活的方式。

## 它解决什么

- 读过很多书，却不知道下一本为什么是它。
- 智能体总在总结内容，却没有问到和自己有关的问题。
- 阅读感受散落在聊天里，过一段时间就找不回来了。

## 工作方式

1. 起步时，根据对使用者的记忆，整理 100 本跨文化、跨学科、跨时代的书，分为十个章程，每程 10 本。
2. 每天针对书单里的一本书做拆解。书单是整理好的地图，不是不可调整的流水线——生活与某本书强烈相关时，可以调序或换书。
3. 每天开始前，先读拆书总索引、近期的拆书记录和记忆内容，把书结合使用者的生活。
4. 按所在"程"选择三层暗门或感受式拆解，最后只提出一个难以用漂亮话滑过去的问题。
5. 用户回答后，给出一次具体反馈，并以原文保存阅读记录。
6. 从这次对话中判断下一本书的方向。

## 每日闭环

每次拆书都不是一次性输出，而是一个不可跳步的闭环：

1. 读取总索引、近期记录和已授权的使用者上下文。
2. 确认今天要拆的书，说明它为什么和当下生活有关。
3. 按所在"程"使用三层暗门或感受式拆解。
4. 只提出一个核心问题，然后等待人的真实回答。
5. 给出一次具体反馈，并强制结束本轮；只有作品与生活强烈摩擦时才商量续谈。
6. 将实际对话原文写入本地笔记，更新进度，并以此校正下一次选书。

完整提示词、分流规则与留档纪律在 [SKILL.md](SKILL.md)；可直接复制 [每日阅读记录模板](templates/daily-reading-record.md)。

## 十个章程

一条由浅入深、最后回到自己的弧线：

1. 地基 · 2. 人性的暗面 · 3. 看见系统 · 4. 意识与感知 · 5. 时间与历史 · 6. 语言与叙事 · 7. 科学与边界 · 8. 自我与关系 · 9. 未来与选择 · 10. 回到自己

第一至第五程、第七程、第九程使用三层暗门；第六、第八、第十程使用感受式。

## 两种拆解形式

### 结构类阅读（三层暗门）

适用于思想、社会、历史、科学与系统类作品：

- 表面论点：作者明确说了什么。
- 核心机制：支撑论点的结构如何运作。
- 最暗的洞察：顺着逻辑再走一步，作品真正危险或未言明的部分。

### 感受类阅读

适用于文学、叙事、个体情感与自我探索类作品：

- 它在讲什么：不是剧情摘要，而是核心叙事。
- 它让你感受到什么：从直接感受到更深一层的不安。
- 它照见了你什么：让作品的处境落到使用者此刻的生活。

## 使用前准备

智能体需要获得用户明确授权的上下文。可先让用户填写 [阅读画像模板](templates/reading-profile.md)，并把阅读记录存放到一个本地 Markdown 文件夹中。

没有持久记忆能力的智能体也可以使用本 Skill，但必须如实说明自己不知道使用者的历史，并索取必要背景。它不应伪造"我记得你"。

## 关于 Obsidian

这套方法只需要一个本地 Markdown 文件夹。Obsidian 只是把这个文件夹可视化出来的工具之一，能带来双向链接和关系图，但不是必需。建议安装以获得更好的查看体验；不装也完全可行，用普通文件夹加任意 Markdown 编辑器管理即可。

## 开始方式

安装后，可以这样说：

- "我想开始长期拆书，先了解我的近况再帮我建一份 100 本书单。"
- "根据我最近在做的项目和已经读过的书，选一本今天最该读的。"
- "用感受式拆解和我一起读《树上的男爵》。"

## 边界

- 用户的回答属于用户，不替其润色为更像正确答案的版本。
- 一次阅读默认只进行一轮提问与反馈；只有当作品和当下生活有强烈摩擦时，才由双方决定续谈。
- 不把私人阅读记录、聊天记录或长期记忆公开到示例、仓库或第三方服务。
- 不以固定书单替代对人的理解。
