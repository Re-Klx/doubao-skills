# 小红书虚拟产品选品助手

一个帮助你把个人经历、工作经验和信息差，转化成可验证、能上架的小红书虚拟产品方向的 Skill。

它不是简单的赛道列表，也不是填表式测评，而是通过不超过 5 轮自然对话，帮你找到：

- 你真正有发言权的经历和隐性知识
- 哪些具体场景会让用户产生付费意愿
- 有真实案例验证的产品切入角度
- 可以直接上架的产品标题、交付骨架和产品矩阵
- 7 天内可以开始执行的第一个动作

## 适合什么时候使用

当你有下面这些想法时，可以使用这个 Skill：

- “我想做小红书虚拟产品，但不知道卖什么。”
- “我有一些工作或生活经验，不知道能不能整理成产品。”
- “我想把经验做成指南、攻略、知识库、模板或清单。”
- “我想用真实案例验证一个产品方向，而不是凭感觉闭门制作。”

## 它会怎样工作

1. 先从职场、装修、旅游、育儿、备考、备婚、兴趣、健康、海外和副业等场景中定位方向。
2. 在 5 轮以内挖掘你的具体经历、隐性知识、踩坑和可交付素材。
3. 还原真实付费场景，判断用户什么时候会愿意掏钱。
4. 用随包的案例摘要验证同类产品、定价和市场缺口。
5. 输出具体产品标题、指南/知识库目录、引流款-利润款-旗舰款矩阵和 7 天行动计划。

## 新手使用说明：怎么下载和安装

### 1. 在哪里下载？

在本页面右上方点击绿色的 **Code** 按钮，再点击 **Download ZIP**。

下载后解压 ZIP 文件，得到 `xhs-product-picker` 文件夹。请下载并保留整个文件夹，不要只下载 `SKILL.md`，因为案例摘要、配置指南和社群图片也属于 Skill 的一部分。

### 2. 怎么安装？

#### 方式 A：使用平台的 Skill 导入功能

如果你使用的 AI 助手提供“导入 Skill”“安装 Skill”或类似入口，选择刚才解压得到的 `xhs-product-picker` 文件夹，按页面提示完成导入。

#### 方式 B：手动放入 skills 文件夹

如果平台没有导入按钮，把完整的 `xhs-product-picker` 文件夹复制到该平台的 `skills` 文件夹中，然后重启或刷新 AI 助手。

安装完成后，确认文件夹内部至少包含：

```text
xhs-product-picker/
├── SKILL.md
├── agents/openai.yaml
├── references/case-data.md
├── references/setup-guide.md
└── assets/community-intro.png
```

之后，在支持 Skill 的 AI 对话中直接说“帮我找一个小红书虚拟产品方向”，或使用 `$xhs-product-picker` 调用它。

Skill 入口文件是 [`SKILL.md`](SKILL.md)，案例资料在 [`references/case-data.md`](references/case-data.md)，在线案例库配置说明在 [`references/setup-guide.md`](references/setup-guide.md)。

## 数据与使用边界

- 小红书虚拟产品案例库（实时更新）：目前已经更新了 400+ 案例，已验证的市场需求。 [点击查看案例库](https://my.feishu.cn/base/FbiAbRsyeaUTiOswW6Uc2l0TnQh?table=ldxov9tq8SMuaL9A)
- 默认使用随包附带的静态案例摘要，不需要飞书权限也能完成基础选品。
- 只有当前运行环境确实有飞书连接器、且用户拥有案例库权限时，才使用在线案例库。
- 没有实时查询时，不会把静态资料描述成“最新数据”。
- 案例库用于推理和验证，不替代对小红书真实需求的测试。
- 做产品前，建议先在小红书搜索标题关键词、阅读同类产品评论，并发布一篇相关内容验证需求。
