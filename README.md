## 在新电脑安装

```bash
# 1. 克隆（公开仓库，无需登录）
git clone https://github.com/Re-Klx/doubao-skills.git

# 2. 把技能目录放入你的技能根目录（如 ~/Doubao/skills/）
mkdir -p ~/Doubao/skills
cp -R doubao-skills/*/ ~/Doubao/skills/
```
